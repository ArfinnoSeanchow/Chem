# Changelog

All notable changes to this project will be documented in this file.


## [2.5.0] - 2026-09-11

### Added
- **Audio Experience (`backsound.mp3`)**: Menambahkan file audio latar (background music/audio) untuk meningkatkan pengalaman interaktif di aplikasi.
- **Brand Identity Asset (`public/chemly-logo1.svg`)**: Varian aset vektor logo Chemly baru untuk mendukung tema atau display resolusi tinggi.
- **Changelog Component (`src/components/changelog.tsx`)**: Komponen UI khusus untuk memuat dan menampilkan riwayat versi serta log pembaruan rilis langsung di aplikasi.
- **Methodology Component (`src/components/methodology.tsx`)**: Modul penjelasan metodologi perhitungan/pendekatan kimia yang digunakan sistem.
- **Dedicated Navbar (`src/components/navbar.tsx`)**: Komponen navigasi independen untuk hierarki navigasi antar-modul yang lebih modular dan terstruktur.

### Changed
- **Header Refactoring (`src/components/Header.tsx`)**: Pembaruan desain dan tata letak header modul laboratorium agar lebih responsif dan sinkron dengan komponen navigasi baru.
- **Landing Page Enhancements (`src/components/LandingPage.tsx`)**: Integrasi navigasi baru, penyesuaian tata letak display branding, dan perbaikan alur antarmuka pengguna utama.
- **Periodic Table Modal Updates (`src/components/PeriodicTableModal.tsx`)**: Penyesuaian modal tabel periodik untuk fungsionalitas interaktif dan integrasi penyisipan elemen kimia.
- **Logo Optimization (`public/chemly-logo.svg`)**: Optimasi file SVG logo Chemly eksisting untuk scaling visual yang lebih bersih.
