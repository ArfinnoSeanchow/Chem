# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](),
and this project adheres to [Semantic Versioning]().

## [0.2.0] - 2026-09-11

### Added
- **Periodic Table Element Insertion**: Kemampuan menyisipkan lambang unsur secara otomatis ke dalam input persamaan reaksi kimia saat elemen diklik.
- **Changelog UI Component**: Komponen antarmuka pengguna untuk menampilkan daftar riwayat pembaruan dan log versi aplikasi secara interaktif.

### Changed
- **Lab Module Header Redesign**: Perombakan tata letak dan hierarki visual pada header modul laboratorium untuk responsivitas yang lebih baik.
- **Global UI Enhancements**: Penyesuaian skema padding, tipografi, dan kontras tombol di seluruh antarmuka lab.

### Fixed
- Sinkronisasi status input ketika berganti antara tampilan tabel unsur dan formulir reaksi.
